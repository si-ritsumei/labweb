Projects

Language Sphere

http://langsphere.org

Indonesia Language Sphere

This project semi-automatically creates bilingual dictionaries among various Indonesian ethnic languages to save these endangered languages.

The Language Grid

https://langrid.org

Language Grid

The Language Grid is a multilingual service platform which enables easy registration and sharing of language services such as online dictionaries, bilingual corpora, and machine translators. Users can construct a multilingual environment to support their activities by combining language services on the Language Grid.

KISSY

www.pangaean.org/event/kissy2019/

KISSY

In Kyoto Intercultural Summer School for Youth(KISSY), children will use a machine translation tool to create amazing works with children from the other countries. This project is organized by NPO Pangaea.

Multilingual Studio

https://langrid.org/developer/

Multilingual Studio

Multilingual Studio is a set of APIs for using the multi-language functions provided by the Language Grid, such as back translation, text-to-speech, multi-hop translation and so on.
