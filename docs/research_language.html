Language Resource

In our lab, we also creating language resources by using and combining cutting-edge technologies. Our projects are listed below.

Pivot-based Bilingual Dictionary Induction for Low Resource Languages

By extending constraints from the current pivot-based induction approach, we proposed constraint-based bilingual lexicon induction for closely related languages, allowing numerous symmetry assumption cycles to reach many more cognates in the transgraph. We also looked for cognate synonyms in order to get many-to-many translation pairings.

A Neural Network Approach to Bilingual Dictionary for Low Resource Language Families

It is important to protect lowーresource language, so we are developing a method to create bilingual dictionary for those low resource lanugages using neural network.

Decentralized Neural Machine Translation

High-quality bilingual data is required to build high-precision neural machine translation, but gathering that high-quality bilingual data from various sources is difficult. To solve the lack of high-quality bilingual corpus problem, we apply federal learning, which is a machine learning method that works in distributed state and does not require data aggregation.

Neural Machine Translation Bias Analysis

Currently neural machine translation can result in biased translations. We are planning to analyze those bias to improve the accuracy of machine translation.
