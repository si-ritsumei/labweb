Overview

Mr. Sunada from our lab gave a research presentation at The Japanese Society for Artificial Intelligence Semantic Web and Ontology Study Group!


Presenter:Sunada Sunada
Title: 「Building an ontology and proposing a system to support the selection of inorganic material analysis methods
Abstract:The purpose of this research is to build an ontology that can be incorporated into a system that recommends the optimal analysis method based on the contents of an analysis request form when analyzing inorganic materials. A concept is defined to break down the analysis purpose stated in the analysis request form into partial acts and output an analysis method to achieve the partial acts. In addition, concepts are defined in conjunction with analytical conditions in order to determine whether the analytical equipment used for the analytical method is appropriate. By doing this, we aim to recommend the optimal analysis method by linking the analysis method and the conditions of the analysis device when an analysis purpose is given.
