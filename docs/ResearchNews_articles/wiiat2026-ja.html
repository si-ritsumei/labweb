著者:Shinichi Nakagawa, Yohei Murakami
タイトル: Hierarchical API Selection for Requirements-Driven Service Composition
概要:Selecting appropriate Web services (APIs) from natural-language user requirements is an important problem in automated service composition. This paper formulates this problem as a multi-label classification task and proposes an API recommendation method based on a pretrained BERT model. However, single-stage multi-label classification loses accuracy as the number of APIs increases. To address this issue, we decompose API selection into multiple layers and construct a multi-layer multi-label classification architecture that progressively refines functional requirements from natural-language descriptions to final API recommendations. We further conduct a design space analysis using the Early Commitment Score, a structural descriptor that projects the high-dimensional discrete design space of hierarchical architectures onto a common one-dimensional axis, enabling systematic comparison of hierarchical configurations and their performance. Experiments on the ProgrammableWeb dataset show that an appropriate multi-layer configuration substantially improves API recommendation performance compared with single-stage classification. The design space analysis further reveals that both excessively early and excessively late candidate-space reduction lead to degraded performance, while intermediate early commitment provides the best balance between progressive candidate reduction and reliable API selection.

著者:Yuki Tobisawa, Yohei Murakami
タイトル: CNP-Based LLM Multi-Agent Systems for Composite Service Recommendation
概要:Selecting Web APIs for a composite service from natural-language requirements is challenging when the candidate set is large. A direct single-agent design that places every API specification in one prompt incurs an increasing long-context burden. We propose a CNP-based LLM multi-agent method in which each contractor holds one API specification and bids on manager-announced tasks. We divide recommendation into core-function decomposition, category mapping, API matching, and API selection, and compare manager-led, contractor-led, and collaborative task-allocation schemes. Experiments with 909 ProgrammableWeb APIs show that manager aggregation outperformed mechanical Top-K selection under the manager-led and contractor-led schemes. Contractor-led was effective for small candidate sets, whereas manager-led degraded more gradually and achieved the highest F1 at 909 APIs. Manager-led achieved F1=0.225 versus 0.130 for single-agent and accounted for 79,129 versus 93,161 tokens per mashup in a post-hoc estimate, although it required at least 111.56 rather than one LLM call; the other distributed schemes accounted for substantially more tokens. Thus, distributing API specifications limits each contractor’s local context, but system-wide accuracy and efficiency depend on reasoning-task allocation and aggregation.
