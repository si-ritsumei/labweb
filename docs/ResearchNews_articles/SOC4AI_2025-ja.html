発表者:松本賢司
タイトル: Guided Reasoning Chains for API Recommendation
概要:The rapid growth in the number of available APIs has made it increasingly challenging for users to discover and compose APIs that fulfill their requirements. Recent studies have applied large language models (LLMs) with multi-step reasoning prompts, such as Chain-of-Thought (CoT) prompting, to API recommendation. However, existing prompt techniques often emphasize generality and domain independence, which can result in incorrect reasoning steps and inappropriate API selection. Therefore, we propose Guided Reasoning Chains (GRC), a novel method that explicitly incorporates hierarchical decomposition based on top-down design principles into the reasoning process. Specifically, our approach uses a top-down decomposition to guide reasoning. It divides the process into four steps: core function extraction, API category selection, candidate listing, and final recommendation. We evaluate our method on real mashup data from ProgrammableWeb using three LLMs: GPT-4.1-mini, LLaMA3:70B, and DeepSeek-R1:70B. Experimental results show that the proposed method consistently outperforms existing baselines on all models, achieving up to 5.3% improvement in F1 score for category reasoning and up to 18.3% improvement in API recommendation.
